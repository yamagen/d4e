# d4e

Dictation For Every Day

## Overview

d4e is a simple dictation tool that allows you to practice your dictation skills.
It includes a set of mp3 files and json files that contain the text for each episode.
The mp3 files are stored in the `mp3` directory and the json files are stored in the `json` directory.

The number of episodes is 150 and the number of sentences is 10 per episode.
